# Healthcare Analytics for Doctor Visits

## 📌 Project Overview

Healthcare organizations collect large amounts of patient data, but understanding the factors associated with doctor visits can be challenging. This project analyzes healthcare data to identify patterns and relationships between patient characteristics, health conditions, and doctor visits.

The project uses Python-based data analysis and visualization techniques to explore healthcare utilization patterns.

## 🎯 Problem Statement

The objective of this project is to analyze patient healthcare data and identify demographic, economic, and health-related factors associated with doctor visits. The analysis focuses on variables such as age, gender, income, illness, health status, chronic diseases, and reduced activity.

## 🔍 Objectives

- Analyze the overall distribution of doctor visits.
- Study doctor visits based on age and gender.
- Examine the relationship between income and doctor visits.
- Analyze the relationship between illness, health status, and doctor visits.
- Study chronic disease and reduced-activity patterns.
- Perform univariate, bivariate, and multivariate analysis.
- Use correlation analysis to identify relationships among numerical variables.
- Create meaningful visualizations and derive useful insights.

## 📊 Analysis Performed

### 1. Data Understanding
- Dataset shape and structure
- Column names and data types
- Descriptive statistics

### 2. Data Cleaning
- Missing value analysis
- Duplicate record detection
- Removal of unwanted index columns
- Data consistency checks

### 3. Univariate Analysis
Analysis of individual variables such as:
- Doctor visits
- Age
- Gender
- Income
- Illness
- Health status
- Chronic diseases

### 4. Bivariate Analysis
Relationships analyzed include:
- Gender vs Doctor Visits
- Age vs Doctor Visits
- Income vs Doctor Visits
- Illness vs Doctor Visits
- Health Status vs Doctor Visits

### 5. Multivariate Analysis
Multiple variables are analyzed together, including:
- Age + Income + Doctor Visits
- Illness + Health + Doctor Visits
- Gender + Health + Doctor Visits
- Chronic Disease + Health + Doctor Visits

### 6. Correlation Analysis
A correlation heatmap is used to understand relationships among numerical variables.
